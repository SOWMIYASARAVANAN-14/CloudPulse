AWS Cloud Architecture Highlights

Amazon CloudFront CDN

Global edge distribution providing browser-trusted HTTPS termination with HTTP-to-HTTPS redirection and a real-time CachingDisabled (TTL=0) policy.

Application Load Balancer

Multi-AZ public ingress distributing HTTP traffic to backend container nodes with 30-second active health checks on /api/health.

EC2 Auto Scaling Group

Elastic compute cluster operating Target Tracking scaling to maintain 50% average CPU utilization with automated self-healing instance replacement.

IMDSv2 & Security Hardening

Instance Metadata Service v2 enforced with hop limit 1 to neutralize SSRF risks. Containers run unprivileged with least-privilege IAM policies.

CloudWatch & SNS Alerting

Proactive CPU utilization alarms (>70%) configured with automated dual-state email notifications dispatching real-time ALARM and OK recovery alerts.

GitOps CI/CD Pipeline

GitHub Actions automated pipeline executing Maven test verification, multi-tagged Docker image builds, and zero-downtime ASG rolling instance refreshes.
